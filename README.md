## 🌟 2.0 全新特性与大版本重塑

### 1. 交互革命：任务栏视线胶囊 & 悬浮抽屉（Taskbar Flyout）
- **左键呼出优雅抽屉 (Flyout)**：单击任务栏胶囊即可呼出 376px 浮动时光看板，拥有毫秒级跳动的 HH:MM:SS 进度大数字、所有期待日子的紧凑时间线、行内快速添加抽屉、以及今日抵达（Day 0）高光祝贺。
- **滚轮顺畅切换**：在任务栏胶囊上轻滚鼠标滚轮，即刻随心切换下一个期待日子。
- **底边微光进度细线**：胶囊底部常驻 2px 极细微光渐变进度条，余量一目了然。
- **全屏沉浸自愈**：原生检测 `SHQueryUserNotificationState`，全屏游戏、观影或 PPT 放映时自动隐退，退出全屏自动毫秒复原。

### 2. 审美跃升：Windows 11 云母与 14 款大师质感皮肤
- **原生 Win11 DWM Mica / Acrylic 毛玻璃**：窗口背景直接融入桌面景深，原生 33 号圆角与高光边缘，彻底告别老旧灰色边框。
- **14 款匠心手调皮肤**：
  - **宣纸·墨韵**（宋瓷灰白微米级纸浆纤维纹理，配金石朱砂印章）
  - **黑胶·琥珀**（深夜流体暗调黑胶，配琥珀暖金微光）
  - **莫奈·睡莲**（印象派水光粼粼柔和蓝绿）
  - **极简·悬浮**、**极光·磨砂**、**奶油·暖麦**、**晨雾·青瓷**、**圣诞·松霜**、**春节·朱砂**等共 14 款。
- **15 组精工矢量语义图标**：新年金龙、圣诞树、中秋满月、生日蛋糕、爱心、火箭发射、旅行行李箱、毕业学士帽等，依名称智能自动匹配。

### 3. 时间引擎：真·农历与全周期周期轮转
- **原生中国农历历法引擎 (`ChineseLunisolarCalendar`)**：完美支持正月初一春节、五月初五端午、八月十五中秋等农历节日，当年过去后全自动递推至次年农历对应公历日，无需人工每年重设！
- **正数日与纪念日**：「已在一起 520 天」、「已坚持跑步 100 天」正向累计。
- **多维度循环**：支持每年、每月（发薪日/还款日）、每周固定周期事件。
- **今日抵达 (Day 0) 盛典**：日子当天呈现高光微光祝贺，不留遗憾。

### 4. 拾光工坊 Studio 2.0：告别置顶干扰与“保存按钮”
- **彻底解除置顶阻挡 (`Topmost = false`)**：再也不会遮挡浏览器、代码编辑器与日常办公窗口。
- **四维侧边栏现代中枢**：
  - 📌 **时光清单**：农历/倒计/正数日徽章、一键启用停用、独立卡片导出。
  - 🎨 **外观画廊**：14 款皮肤色彩画廊，**顶部实时 1:1 任务栏胶囊沙盒**，所改即所见。
  - 🖼️ **社交工坊**：内嵌式海报与卡片工坊，所见即所得。
  - ⚙️ **系统偏好**：单日/双日/平铺/轮播多模态切换、开机自启无缝托盘控制。
- **即时无感自动保存 (Zero-Friction Live Sync)**：彻底移除“保存并应用”按钮。每一次开关、色板点击或文本录入，立刻持久化并毫秒同步至任务栏！

- **彻底根治“多余大背景”**：导出与复制的图片就是 100% 纯净海报本身（1080×1440、1080×1080、1600×900 或 1080×2340），绝无任何多余黑底边框或外部点阵！

  3. **登机牌·时光票根风**（机场登机牌圆弧打孔裂口、虚线撕裂线、双色存根）

## 快捷操作指南

| 手势 / 操作 | 触发效果 |
| --- | --- |
| **鼠标左键单击任务栏** | 呼出 / 收起时光抽屉 (Flyout)，查看实时时分秒看板与快捷添加 |
| **鼠标滚轮在任务栏滚动** | 顺次轮播切换下一个关注的日子 |
| **鼠标按住左键拖动** | 自由平移任务栏胶囊至任意心仪水平位置并自动记忆 |
| **鼠标右键单击任务栏** | 调出 Fluent 右键菜单：进入「拾光工坊 Studio」或直接「生成社交卡片」 |
| **工坊内拍立得相纸** | 直接将电脑上的任意图片拖入左侧工作台，即刻换上专属照片 |

## 从源码构建与测试

本项目保持**零外部依赖**（纯 C# 4.0 / WPF，直接使用 Windows 系统自带的 `csc.exe` 即可编译）。

```powershell
# 编译并运行完整单元测试集（包含 80 项自动化边界验证）
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1

# 打包发布版 Zip 与 SHA256 校验档
powershell -ExecutionPolicy Bypass -File .\scripts\package.ps1 -Version 2.0.0
```

测试集已覆盖：农历转换与闰月边界、公历/农历节日自动递推、正数日计算、14 种皮肤调色板、5 套模板 × 4 种比例渲染分辨率、Win11 DWM 属性验证。
